## About me

I'm **Abdulrawof Totakhil**, an **Oracle Database Administrator and multi-platform database professional based in Kabul, Afghanistan**. My work is grounded in **hands-on experience supporting enterprise banking database environments**—from daily operations and incident response to infrastructure modernization, high availability, disaster recovery, and performance optimization.

I work across the full DBA lifecycle: **design, deployment, patching, monitoring, troubleshooting, backup validation, recovery readiness, security, and automation**. I enjoy turning complex database problems into clear, reproducible solutions and sharing what I learn with the wider technical community.
